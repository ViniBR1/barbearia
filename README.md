\# 🪒 Empório Barbe - Sistema para Barbearia



Sistema completo para barbearia com agendamentos, assinaturas, pagamentos via Mercado Pago e muito mais!



\## 🚀 Funcionalidades



\- ✅ Barbearia por assinatura e corte avulso

\- ✅ Layout moderno com carrossel de fotos

\- ✅ Agendamentos com pagamento via Pix ou Cartão (Mercado Pago)

\- ✅ Painel administrativo completo

\- ✅ Edição de preços e tipos de corte

\- ✅ Fila de espera com tempo estimado

\- ✅ Programa de fidelidade (corte 4 ganhe 1)

\- ✅ Plano familiar

\- ✅ Controle de estoque

\- ✅ Multi barbearia

\- ✅ Confirmação via webhook



\## 🛠️ Tecnologias



\- \*\*Backend\*\*: Node.js + Express

\- \*\*Banco de Dados\*\*: PostgreSQL (Neon.tech)

\- \*\*Pagamentos\*\*: Mercado Pago

\- \*\*Hospedagem\*\*: Vercel

\- \*\*Frontend\*\*: HTML + CSS + JavaScript
